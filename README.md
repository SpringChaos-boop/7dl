# Семидневный лабиринт CatWar

## О скрипте

**Семидневный лабиринт CatWar** — скрипт для браузеров с поддержкой UserScript (Tampermonkey, Violentmonkey, Greasemonkey), добавляющий вспомогательные инструменты для CatWar:

- встроенную **интерактивную карту Семидневного лабиринта (7ДЛ)**;
- **таймеры** локального времени и времени до конца текущего действия персонажа;
- **автоматическое определение** текущей локации лабиринта по картинке переходов на игровом поле.

Оригинальная идея и первая версия — **Медвянка [406811]**, доработка и текущая поддержка — **Горицвет [1705753]**.

## Возможности

### Карта 7ДЛ
- Сетка **10 × 6** с подсветкой клеток:
  - 🟩 **зелёный** — переходы к ОВ (ОП);
  - 🟦 **синий** — переходы к МВ (МП);
  - ⬜ **нейтральный** — остальные клетки локации.
- Плавающее окно поверх страницы — можно **перетаскивать** и **сворачивать**.
- Позиция и состояние окна **сохраняются** между сессиями.
- **Ручной режим**: выбор лабиринта (нижний/верхний этаж) и номера локации кнопками `ОП <` / `> МП` или вводом числа.
- **Автоматический режим** (тумблер «Обновлять при переходе»): карта сама обновляется при каждом шаге персонажа, определяя локацию по комбинации переходов на клетках.

### Таймеры
- На **главной странице** под списком персонажей отображается:
  - текущее локальное время с днём недели и датой;
  - обратный отсчёт до конца действия персонажа.
- В лабиринте таймер действия **парсится из игрового сообщения**.

### Темы оформления
- **Светлая** (по умолчанию);
- **Тёмная**;
- Переключение — кнопкой `☾ / ☀` в шапке панели, выбор сохраняется.

## Установка

1. Установите менеджер пользовательских скриптов:
   - [Tampermonkey](https://www.tampermonkey.net/) (Chrome, Edge, Firefox, Safari, Opera);
   - [Violentmonkey](https://violentmonkey.github.io/) (Chrome, Firefox, Edge);
   - [Greasemonkey](https://www.greasespot.net/) (Firefox).
2. Откройте панель управления расширением → **«Создать новый скрипт»**.
3. Удалите шаблон и вставьте код скрипта целиком.
4. Сохраните (`Ctrl+S`) и обновите страницу.
5. Зайдите на CatWar — панель карты появится в левом верхнем углу на страницах лабиринта (`/cw3`, кроме `/cw3/kns` и `/cw3/jagd`).

## Использование

### Плавающее окно
| Действие | Как сделать |
|---|---|
| Переместить | Потянуть за **заголовок** панели («Карта 7ДЛ») |
| Свернуть / развернуть | Кнопка **— / +** в шапке |
| Сменить тему | Кнопка **☾ / ☀** в шапке |
| Закрыть | Обновить страницу или отключить скрипт в менеджере |

Позиция и свёрнутость окна запоминаются автоматически.

### Автоматическое обновление карты
1. Включите тумблер **«Обновлять при переходе»**.
2. Играйте как обычно — карта будет обновляться при каждом перемещении.
3. Выключите тумблер, чтобы вернуться к ручному режиму.

> В автоматическом режиме, если персонаж оказался впервые в неоднозначной ситуации (несколько локаций с одинаковым набором переходов и неизвестно направление движения), карта может не обновиться до следующего шага. Это нормальное поведение: скрипт ждёт дополнительной информации, а не угадывает.

### Совместимость
- Chrome / Edge / Opera (Blink) — да;
- Firefox (Gecko) — да;
- Safari (WebKit) — да (нужен Tampermonkey);
- Мобильные браузеры с поддержкой UserScript — ограниченно (нужен браузер с менеджером скриптов).

## Известные ограничения

- **Неоднозначные локации.** Если в лабиринте есть локации с идентичным набором переходов, скрипт не всегда может определить текущую — нужно пройти ещё один шаг.
- **Зависимость от вёрстки.** Логика опирается на ID и классы. При изменении вёрстки CatWar скрипт может потребовать правок.
- **Сетка только 10 × 6.** Если карта лабиринта будет расширена, понадобится адаптация.
- **Один персонаж.** Скрипт рассчитан на одного активного персонажа; данные хранятся в локальном хранилище, без разделения по аккаунтам.
- **Внешний хостинг JSON.** При недоступности `reireirei72.github.io` карта не загрузится (таймеры продолжат работать).
